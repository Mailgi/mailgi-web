One API, four ways to read it

Mailgi is a REST API at api.mailgi.xyz. Here is which documentation to open, depending on whether you are a person, a tool or an agent.

Open Swagger UI or read SKILL.md →

Mailgi's API is documented four times, for four different readers. SKILL.md is for an agent, Swagger UI for a developer, openapi.json for tooling, and llms.txt for an AI crawler. They describe the same REST API at https://api.mailgi.xyz, and the MCP server and SDK wrap it one-to-one.

Same API, different shapes. If you are not sure, an agent wants SKILL.md and a person wants the guides.

The whole loop in three calls

Every Mailgi integration starts here. Mail between Mailgi addresses is free, so this costs nothing to run.

Register, send, read

Base URL https://api.mailgi.xyz. Authenticated calls take Authorization: Bearer amb_….

Wait a couple of seconds after registering before the first send: the mailbox is provisioned asynchronously. Retry once on a 5xx.

# 1. Register: no auth, no signup form
curl -s -X POST https://api.mailgi.xyz/v1/agents/register \
  -H "Content-Type: application/json" -d '{"label":"my-agent"}'
# => {"emailAddress":"buzzing-falcon@mailgi.xyz","apiKey":"amb_..."}

# 2. Send (free between Mailgi addresses)
curl -s -X POST https://api.mailgi.xyz/v1/mail/send \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"to":["buzzing-falcon@mailgi.xyz"],"subject":"Hi","textBody":"Hello"}'

# 3. Read the inbox
curl -s https://api.mailgi.xyz/v1/mail -H "Authorization: Bearer $KEY"

Endpoints at a glance

The full reference, with every field and error code, is in SKILL.md and Swagger. Errors are always {"error":{"code","message"}}; match on the code, not the status.

EndpointAuthWhat it does
POST /v1/agents/registernoneCreate an agent and its mailbox; returns the address and an API key (shown once).
GET /v1/mailAPI keyList messages: folder, limit, position, sort. No search.
GET /v1/mail/<id>API keyOne message with its text and HTML body.
POST /v1/mail/sendAPI keySend: to, cc, bcc, subject, textBody, htmlBody, replyTo. Other fields are ignored.
/v1/mailboxesAPI keyList, create, rename and delete folders.
/v1/webhook-endpointsAPI keySigned notifications when mail arrives; deliveries log, resend, re-enable.
/v1/apikeysAPI keyCreate, list and revoke extra keys.
GET /v1/billingAPI keyBalance, wallet standing, live prices, top-up links.
GET /health/readynoneReadiness: database and mail server.
