What shipped, and when

2026-10-31

Hosted MCP server

  • Mailgi is now an MCP server at https://api.mailgi.xyz/mcp (Streamable HTTP, stateless). Every tool is a 1:1 proxy of a REST endpoint, with the same limits and billing. Works with Claude Code, Claude Desktop and Cursor. Setup.
  • SKILL.md 1.6.0 documents it in §15.
2026-10-30

Pay-as-you-go pricing

  • Receiving stays free, and so does mail between your own agents. Mail that leaves Mailgi is paid from a prepaid balance: $0.0005 per external recipient, $0.02 once per new address, and $0.25 per GB-month of storage above 10 MB. Pricing.
  • Anyone can top up any agent by card at app.mailgi.xyz/topup, without an account. A send the balance cannot cover is refused whole with an itemised 402 PAYMENT_REQUIRED.
  • Reads carry a billing notice when the balance runs low, with a top-up link the agent can forward.
  • TypeScript SDK and CLI 0.2.0 on npm: PaymentRequiredError, the billing notice, and webhook types.
2026-09-03

Inbound webhooks

  • Register an HTTPS endpoint with POST /v1/webhook-endpoints and Mailgi POSTs a signed notification when mail arrives: sender, time, size and a fetch URL, never the content. Delivery log, resend and re-enable included, in the API and the dashboard.
  • Polling still works and is still the simpler choice for most agents.
2026-09-01

Agent-to-agent mail gets its own allowance

  • Mail between Mailgi agents is counted on its own allowance (1,000 an hour, 5,000 a day per agent), so coordinating with other agents never uses your external sending quota.
  • Three working guides: verification codes, support inboxes and agent-to-agent email.
2026-08-30

SKILL.md on ClawHub, and a published comparison

  • SKILL.md is versioned and published as an OpenClaw skill on ClawHub.
  • New pages: how to give an AI agent an email address, the comparison and pricing with every limit stated.
2026-08-26

Custom domains send with your own DKIM, SPF and DMARC

  • Once a domain's inbound records verify, the dashboard generates the outbound set: DKIM under Mailgi's own selector, a MAIL FROM subdomain for SPF alignment, and a recommended DMARC record. Sending stays blocked until they verify.
  • Dashboard sign-in by email and a one-time code.
2026-08-25

Organisations and custom domains

  • Attach your own domain, verify it over DNS, and issue registration tokens so agents register chosen addresses like support@yourdomain.com.
  • Sending caps per agent and per organisation, scaled by domain age, with automatic suspension on bounces and complaints.
2026-04-18

TypeScript SDK and CLI

  • npm install @mailgi/mailgi: a typed client whose methods map 1:1 to the REST API, plus the mailgi command-line tool.
