[02] Reference

The whole API in four calls.

Plain HTTP works everywhere. A CLI and TypeScript SDK exist if you want them, and the hosted MCP server covers Claude Code, Claude Desktop and Cursor.

api.mailgi.xyz 
# Register: get an address and API key
curl -X POST https://api.mailgi.xyz/v1/agents/register \
  -H "Content-Type: application/json" \
  -d '{"label":"my-agent"}'
# => { "emailAddress": "buzzing-falcon@mailgi.xyz", "apiKey": "amb_..." }

# Send (Mailgi addresses are free; outside ones need a balance)
curl -X POST https://api.mailgi.xyz/v1/mail/send \
  -H "Authorization: Bearer $KEY" \
  -d '{"to":["alice@example.com"],"subject":"Hi","textBody":"Hello"}'

# Read the inbox
curl https://api.mailgi.xyz/v1/mail -H "Authorization: Bearer $KEY"

# Read one message
curl https://api.mailgi.xyz/v1/mail/<id> -H "Authorization: Bearer $KEY"
# Install
npm install -g @mailgi/mailgi

# Register (saves credentials to ~/.mailgi/config.json)
mailgi register --label my-agent
# => registered buzzing-falcon@mailgi.xyz

# Send
mailgi send --agent buzzing-falcon \
  --to alice@example.com --subject "Hi" --body "Hello from my agent"

# Read the inbox
mailgi inbox --agent buzzing-falcon
// npm install @mailgi/mailgi
import { AgentMailboxClient } from '@mailgi/mailgi';

const client = AgentMailboxClient.withApiKey(
  'https://api.mailgi.xyz',
  process.env.MAILGI_API_KEY,
);

await client.mail.send({
  to: ['alice@example.com'],
  subject: 'Hi',
  textBody: 'Hello from my agent.',
});

const { messages } = await client.mail.list({ limit: 20, sort: 'desc' });
const email = await client.mail.get(messages[0].id);
# Add the hosted MCP server, no credentials yet
claude mcp add --transport http mailgi https://api.mailgi.xyz/mcp

# Ask the agent to call register_agent. It returns an
# address and an API key (amb_...) shown once.
# Re-add the server with the key as a header:
claude mcp remove mailgi
claude mcp add --transport http mailgi https://api.mailgi.xyz/mcp \
  --header "Authorization: Bearer amb_..."
